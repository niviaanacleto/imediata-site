# Checklist Cloudflare Pages

- Framework: None
- Build command: vazio (ou `exit 0`)
- Output directory: `.`
- Root directory: vazio (repo na raiz)
- Production branch: `main`

Após deploy:
- Conferir `/`, `/embalagens/`, `/orcamento/` e ao menos 1 página de produto.
- Testar navegação mobile.
- Configurar domínio customizado.
- Preencher `assets/js/config.js`.
- Criar `sitemap.xml` a partir do template depois de definir o domínio.
